# 아날로그 편집 콜라주 인트로 생성기 (Vox 스타일)

오디오북형 다큐 채널용 **타이틀·인터스티셜 시스템**을 파이썬으로 구현했습니다.
깔끔한 모션그래픽이 아니라, 인쇄물을 손으로 오려 붙이고 사진으로 찍은 듯한 **촉각적인 편집 콜라주**가 목표입니다.
첫 적용 사례는 내레이션 `audio/gimje_1997_intro.mp3` (잊혀진 X파일 — 1997 김제 농협 여직원 실종사건, 2분 13초)입니다.

```bash
pip install -r requirements.txt
python render.py storyboards/gimje_1997.json                  # 매번 새 시드, chaos 0.4
python render.py storyboards/gimje_1997.json --seed 1997 --chaos 0.4   # 같은 시드+chaos = 같은 프레임
python render.py storyboards/gimje_1997.json --stills 3 10.5 31.9 --scale 0.5   # 정지 프레임 미리보기
```

결과물은 `output/<스토리보드>_seed<시드>_chaos<값>.mp4`와, 그 빌드에서 시드가 고른 값(장면별 강조 방식·가장자리 처리 등)을 기록한 같은 이름의 `.json`입니다.

## 1. 기획

### 내레이션 분석
- 구조: **훅 질문 → 배경(1997·김제) → 인물(여직원·이장) → 실종 → 의혹(단순 가출·무언의 압박·단 한 사람·단 한 곳) → 12년 뒤 발견 → 질문 2개 → 메인 타이틀 → 구독/댓글 CTA**.
- 이탈 방지 설계: 문장마다 새 이미지가 "손으로 놓이듯" 들어오고, 핵심 단어가 들릴 때 제목이 착지하며, 결정적 문장(`바로 마을 이장이었다는 것이죠`, `바로 저수지 수문 하부였습니다`)에 카메라가 히어로로 푸시인합니다.
- 실존 인물 보호: 인물은 모두 **뒷모습**, 문서의 개인정보는 `박 ○ ○`로 가림. 소품 문구는 내레이션이 말한 사실만 재진술합니다.
- 타이밍: 로컬 Whisper(large-v3-turbo) + VAD로 전사한 구간 타임스탬프(`data/transcript_gimje_1997.json`)에 음절 비례로 단어 시점을 추정해 제목 등장·푸시인 시점을 맞췄습니다.

## 3. 새 영상에 쓰는 방법 (매일 작업 흐름)

1. **내레이션 전사** (선택): `python tools/transcribe.py audio/새대본.mp3 --out data/새대본.json` → 문장별 시작/끝 시간.
2. **이미지 준비**: 실사 사진(또는 AI 생성 이미지)을 `sources/이름.jpg`로 넣고 `sources/sources.json`에 옵션 기록
   ```json
   { "man_back": {"method": "key", "person": true},
     "sluice_gate": {"method": "isnet"},
     "mountains": {"method": "none"} }
   ```
   - `method`: `auto`(알파 있으면 사용, 없으면 ISNet) · `isnet` · `u2net` · `key`(단색 배경) · `none`(오려내지 않고 사각 인화로만 사용)
   - `person: true` → 띠 분할 대상. 선택 착색을 쓰려면 같은 크기의 흑백 마스크 `이름.part.png`(정의 부위=흰색)를 옆에 둡니다.
   - 생성 이미지 오른쪽 아래의 작은 워터마크는 자동으로 지웁니다(`--no-watermark-fix`로 끔).
3. `python prep_subject.py --batch sources/` → `assets/`에 배경 제거·흑백 결과와 메타데이터 생성.
4. **스토리보드 JSON 작성**: 장면별 `start/end`, `hero`(에셋·높이·x·top·등장 시각), `lockup`(설명줄·제목·등장 시각), `support`, `beats`(푸시인/풀백 시각), `diagrams`, `transition`(cut/push/slide).
5. `python render.py storyboards/새대본.json` → 마음에 드는 우연이 나오면 출력 파일명의 시드를 `--seed`로 고정.

좌표는 모두 **정지 상태 화면 픽셀**(화면 중앙이 0,0, 위가 음수)입니다. 에셋이 없으면 `fallback` 이름으로 대체하거나 해당 요소를 건너뜁니다.

### 코드 생성 피사체
`python make_sources.py`는 사진이 없을 때 쓰는 절차적 이미지(지도·문서·서류철·표지판·달력·스티커·테이프, 그리고 인물·수문·밥상·콘크리트·시골집·산 대체본)를 만듭니다.
같은 이름의 사진이 `sources/`에 있으면 사진이 우선합니다. 지도는 통계청 경계(`data/korea_map.json`, `tools/build_map_data.py`)로 그린 실제 지도입니다.

## 4. 이번 빌드 & 검증

- 최종본: \`--seed 1997 --chaos 0.4\`, 1920×1080 30fps H.264(CRF 21) + AAC 192k, 2분 13초. 빌드 매니페스트(\`output/*.json\`)에 장면별로 시드가 고른 강조 방식·가장자리 처리·띠 개수가 기록됩니다.
- 재현성: 같은 시드·chaos로 따로 두 번 렌더한 프레임의 md5가 동일, 시드를 1만 바꿔도 배치·가장자리·회전·배경이 모두 달라짐을 확인했습니다.
- chaos 0 → 띠가 정렬되고 회전이 거의 없는 깨끗한 구도, chaos 1 → 띠 오프셋 ±8.5%, 회전 ±6°, 요소 회전 ±14°, 배경 조각 최대 14장.
- 사진을 받으면: \`sources/\`에 같은 이름(\`man_back\`, \`woman_back\`, \`sluice_gate\`, \`soban\`, \`concrete\`, \`rural_house\`, \`mountains\`)으로 넣고 \`prep_subject.py --batch sources/\` 후 같은 시드로 다시 렌더하면 연출은 그대로, 피사체만 실사로 바뀝니다.
